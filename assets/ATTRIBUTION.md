# Asset provenance

## Original procedural content

The island, plants, resource nodes, player silhouette, building pieces, interface
copy, and palette are new compositions implemented in `game/`. No screenshots,
models, textures, music, characters, logos, source code, or private APIs from
Bloxfun/Lightus are included. The working title Pocket Oasis / واحة صغيرة has
not been trademark-cleared.
