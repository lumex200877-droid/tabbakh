# واحة صغيرة | Pocket Oasis

## العب من الموبايل الآن

افتح **المعاينة المباشرة في المحادثة** واضغط **ادخل واحتي**. لا تحتاج كمبيوتر أو تثبيت Godot لتجربة هذه النسخة. العصا أسفل اليسار للحركة، زر اليمين للتفاعل، والشريط السفلي للبناء والتصنيع والحقيبة. اضغط البوصلة بجوار اسم الوادي لنظرة عامة، واسحب العالم لتدوير الكاميرا.

هذه **نسخة ويب فعلية بـThree.js**، وليست تشغيلًا أو تصديرًا لملفات Godot ولا APK. جرى اختبار الرسم WebGL واللمس والتصنيع والبناء والزراعة والحفظ وإعادة التحميل في Chromium آلي بمحاكاة شاشة موبايل، وليس على هاتف المستخدم الحقيقي. مشروع Godot الأصلي باقٍ كما هو؛ اختبارات محركه لا تزال غير منفذة.

- تحتاج اتصالًا لفتح المعاينة وتحميلها. لا توجد حسابات أو لعب جماعي أو خدمة خلفية للّعب، ولا ادعاء أن الصفحة PWA أو أنها ستفتح بلا إنترنت لاحقًا.
- تقدم المتصفح يُحفظ في localStorage على **نفس المتصفح ونفس رابط المعاينة**. وضع التصفح الخاص، حظر التخزين، تغيير الرابط أو مسح بيانات الموقع قد يفقده. ليس حفظًا سحابيًا، ولا يتبادل ملفات الحفظ مع Godot.
- ميزات هذه النسخة: كاميرا منظور من خلف الشخصية، وادٍ بتضاريس ونهر وجسرين، موارد محدودة، وصفة ألواح، ست قطع بناء قابلة للتركيب (أرضية، حائط، سياج، مدخل، شباك، سقف)، أربعة أحواض وبذر وري ونمو وحصاد. رسوم هندسية أصلية وواجهة عربية؛ نغمات تفاعل بسيطة اختيارية، دون أصول مدفوعة.
- تستخرج `scripts/export_web_data.py` مواقع وقيَم العالم من `game/world_data.gd`؛ منطق JavaScript مستقل ومغطى باختبارات منفصلة، وليس نفس runtime الخاص بـGodot. تضاريس الوادي ووصفات أجزاء البيت الإضافية تخص الويب؛ ملف البيانات المُولّد يبقى مطابقًا لمصدر Godot.

### بيتك الصغير في نسخة الوادي

ابنِ أرضية ثم غيّر القطعة إلى حائط. «تدوير» يختار حافة الأرضية؛ تستطيع تركيب أربع حواف ومدخل مفتوح وشباك ثم سقف فوق نفس الأرضية. السقف يحتاج حائطين على الأقل. تُحفظ القطع مع تقدمك، ويُرحّل حفظ نسخة الجزيرة القديمة دون حذف المخزون. قرب النهر والبداية والزرع والموارد محجوز للبناء. الكوخ غير المكتمل ومنضدة العمل في المشهد **زينة**، لا بيتًا جاهزًا تدّعي اللعبة أنك بنيته. الحصى يحدد المرج القابل للمشي (نصف قطره 17 وحدة)، والتلال أبعد منه منظر وليست عالمًا مفتوحًا قابلًا للاستكشاف.

الخامات الأصلية المولدة بالذكاء الاصطناعي موثقة في `web/assets/README.md`. صورة التصور المختارة مرجع اتجاه فني وليست وعدًا بتطابق التفاصيل مع الرسم الآني.

### تشغيل/فحص نسخة المتصفح للمطور

```bash
npm ci
npm run dev -- --port 5173
# في جلسة منفصلة:
npm test
npm run check:world
npm run test:browser  # يحتاج خادم التطوير أعلاه، Linux وأدوات QA الاختيارية
npm run build
npm run preview -- --port 5173
```

خادم المعاينة يربط `0.0.0.0` ويقبل نطاق معاينة Arena. لا أكواد متصفح تطلب localhost كخدمة خلفية. build الإنتاج موجود في `dist/`، ويستبعد أدوات رصد الاختبار التطويرية. تراخيص Three.js وLucide والخط في `public/THIRD_PARTY.txt` وتُنسخ إلى build.

**نتائج التحقق:** 22 اختبار منطق JavaScript + 29 تحقق متصفح فعلي (بما فيها WebGL ولمس متعدد وحفظ وإعادة تحميل) + 6 اختبارات هيكل Python نجحت. نجح build إنتاج. صور QA محلية في `.cache/oasis-tests/` غير متتبعة. لم نقس FPS أو الحرارة على هاتف حقيقي.

## مشروع Godot الأصلي (مسار أندرويد لاحقًا)

**نموذج لعبة 3D أصلية لأندرويد، فردي ودون إنترنت.** اسم عمل مؤقت، وليس علامة تجارية مفحوصة. المشروع يستخدم Godot وGDScript، بلا خوادم أو حسابات أو مشتريات أو أصول مدفوعة.

> **حالة مشروع Godot فقط:** ملفات مشروع قابلة للتعديل، وليست APK. تم فحص الصياغة والتنسيق وهيكل المشروع محليًا؛ لم يُشغّل محرك Godot أو اختبارات اللعبة الفعلية في هذه البيئة لأن تنزيل المحرك تعطل بسبب قيود الاتصال. لم يُختبر على هاتف ولم يتم قياس الأداء. لا نعتبره جاهزًا للنشر.

## الموجود في الكود

- جزيرة صغيرة برسومات هندسية أصلية، شخصية وكاميرا قابلة للدوران.
- عصا لمس وأزرار عربية، مع تحكم لوحة مفاتيح للكمبيوتر.
- 12 شجرة و8 صخور، جمع خشب وحجر بكميات محدودة.
- حقيبة، تحويل خشبتين إلى لوح، وبناء أرضية/حائط/سياج على شبكة.
- 4 أحواض: بذر ثم ري ثم نمو لمدة 30 ثانية من **اللعب النشط** ثم حصاد يعيد بذورًا.
- حفظ محلي بإصدار، تحقق من البيانات، كتابة مؤقتة ونسخة سابقة واسترجاع عند تلف الملف.
- قائمة توقف اللعب، وبدء عالم جديد بتأكيد صريح.

**غير موجود بعد:** عالم ضخم، قتال، حيوانات مساعدة، شخصيات متعددة، اقتصاد، تعاون أو حسابات، محرر شخصية، موسيقى أو أصوات. البناء إضافة فقط في هذا النموذج؛ لا هدم أو استرداد مواد. لا إعادة نمو للأشجار والصخور حاليًا. هذه حدود نموذج أولي وليست وظائف مخفية.

## التشغيل على الكمبيوتر

1. ثبّت نسخة **Godot Standard 4.4.1**، وليس إصدار .NET. لا يحتاج المشروع C# أو npm.
2. افتح Godot واختر **Import** ثم ملف `project.godot` في جذر المشروع.
3. انتظر استيراد الخط، ثم اضغط **F5** لتشغيل اللعبة.
4. ابدأ بجمع أربع خشبات وصنع لوحين، ثم اجمع حجرًا وابنِ أرضية في مكان مفتوح.
5. اذهب للأحواض البنية بجوار الممر: تفاعل للبذر، مرة أخرى للري، وانتظر ثم احصد.

دليل مبسط وتصدير أندرويد: [ابدأ هنا](docs/START-HERE.ar.md).

## الاختبارات

فحوص مصدر فقط، Python 3.11 مقترح:

```bash
python3 -m pip install -r requirements-dev.txt
gdlint game/*.gd tests/*.gd
gdformat --check game/*.gd tests/*.gd
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

اختبارات منطق اللعبة والحفظ والمشهد **تحتاج Godot فعلًا**. غيّر `godot` لاسم الملف التنفيذي عند الحاجة:

```bash
godot --headless --editor --path . --import
godot --headless --path . --script tests/test_game.gd
godot --headless --path . --script tests/test_scene.gd
```

لا تختبر الفيزياء والرسوم واللمس بالنظر إلى نجاح فاحص الصياغة. قائمة اختبار الهاتف في `docs/TESTING.ar.md`. توجد إجراءات GitHub Actions لتشغيل الفحص والمحرك عند دفع التغييرات؛ لم تُشغّل هنا ولم نعمل commit أو push.

## نسخة مصدر مضغوطة

```bash
python3 scripts/package_project.py
```

ينتج `build/pocket-oasis-source.zip`؛ لا يحتوي كاش المحرك أو أسرارًا أو ملفات مهارات التطوير. هذا **مشروع مصدر وليس ملف تثبيت أندرويد**.

## الملفات

- `game/island_state.gd`: منطق موارد وتصنيع وبناء وزراعة وتحقق الحفظ، مستقل عن العرض.
- `game/save_store.gd`: حفظ واسترجاع ونسخة احتياطية.
- `game/main.gd`: ربط اللعب والتحكم والعالم.
- `game/world_art.gd`: مجسمات أصلية مكونة من أشكال المحرك.
- `game/hud.gd` و`virtual_stick.gd`: الواجهة العربية والتحكم باللمس.
- `assets/design-tokens.json`: ألوان وأدوار تباين الواجهة.
- `export_presets.cfg`: إعداد أندرويد تجريبي arm64 دون صلاحية إنترنت؛ يحتاج SDK وقوالب تصدير.
- `tests/`: اختبارات مصدر واختبارات GDScript منفصلة.
- `replica/`: بحث وخطة سابقة وسجل تنفيذ؛ خطة الفريق الكبيرة أصبحت مرجعًا مؤجلًا وليست التزامنا الحالي.
- `.claude/skills/`: مهارات Replica المثبتة لتطوير المشروع، لا تدخل اللعبة المصدّرة.

## الأصول والحقوق

الكود والمجسمات الهندسية الجديدة مكتوبة لهذا النموذج، دون استخدام ملفات اللعبة المرجعية أو كودها أو خريطتها أو علامتها. الخط **Noto Sans Arabic** مرخّص SIL OFL 1.1، والنص الكامل محفوظ في `assets/fonts/OFL.txt` مع توثيق المصدر في `assets/ATTRIBUTION.md`. عند التوزيع احتفظ بإشعارات تراخيص الخط والمحرك وأي أصل يضاف لاحقًا.
