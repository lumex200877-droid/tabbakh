# نَوْر — مساعدك الشخصي المحلي

واجهة عربية RTL لمساعد شخصي محلي: محادثة مع Ollama ومقارنة نموذجين، وضع صوت متتابع حسب دعم المتصفح، استوديو لتوليد نموذج صفحة ويب، استوديو مسودات للمحتوى، اختصارات روابط لتطبيقات تختارها يدوياً، بحث يفتح Bing، ومهام ومكتبة محلية. متجاوبة مع الهاتف، بلا اشتراك سحابي عند تشغيل نموذج محلي.

## تشغيل الواجهة

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`. للتثبيت كتطبيق ويب (PWA) على الهاتف، يجب استضافة الملفات عبر HTTPS ثم اختيار «إضافة إلى الشاشة الرئيسية» من المتصفح. التسجيل كـPWA يتيح حفظ واجهة التطبيق الأساسية للعمل دون اتصال؛ ميزات الذكاء الاصطناعي والبحث تحتاج اتصالاً بخدمة النموذج/الإنترنت.

## توصيل نموذج محلي عبر Ollama

1. ثبّت Ollama من [ollama.com](https://ollama.com) على الجهاز الذي سيشغّل النموذج.
2. نزّل نموذجاً يلائم الذاكرة المتاحة، مثلاً `ollama pull qwen2.5:3b`.
3. في نَوْر > الإعدادات، أدخل عنوان Ollama واسم النموذج، ثم اختبر الاتصال.
4. لو المتصفح يمنع الاتصال بسبب CORS، اضبط `OLLAMA_ORIGINS` وفق توثيق Ollama لنطاق الواجهة ثم أعد تشغيل الخدمة. لا توسّع السماح على شبكة عامة.

ملاحظة: صفحة الويب الموجودة على الهاتف لا تستطيع عادةً الوصول إلى Ollama المثبت على كمبيوتر آخر عبر `localhost`؛ يلزم إعداد شبكة محلية آمن وعنوان الجهاز الصحيح، أو تشغيل Ollama على الهاتف إن كان مدعوماً وملائماً. لا تفتح منفذ Ollama للإنترنت.

## ما الذي يعمل حالياً؟

- المحادثات، المهام، الإعدادات، اختصارات الروابط، وملفات النصوص تحفظ في `localStorage` على هذا المتصفح فقط.
- استوديو المحتوى ينشئ مسودة (فيديو قصير، منشور، وصف منتج، بريد، أو خطة أسبوعية) بواسطة النموذج المحلي؛ لا ينشر تلقائياً ولا ينشئ ملف فيديو نهائياً.
- «تطبيقاتي» يخزن روابط تختارها يدوياً ويفتحها بموافقتك؛ لا يكتشف التطبيقات المثبتة ولا يقرأ واجهاتها أو يتحكم بها.
- المحادثة وتوليد صفحة HTML يستخدمان واجهة Ollama المحلية عند ضبطها. أداة بناء التطبيقات تولّد **نموذج ويب HTML واحداً** يمكن معاينته وتنزيله، وليست منشئ تطبيق هاتف أصلي ولا تنشر شيئاً تلقائياً.
- المحادثة تدعم قراءة الرد بصوت الجهاز (Speech Synthesis)، وإملاء السؤال، ووضع محادثة صوتية متتابعة إن كان المتصفح يدعم Speech Recognition. هذا ليس اتصالاً صوتياً منخفض التأخير مثل مكالمة هاتفية، وقد يُعالج الإملاء عبر مزود المتصفح/النظام وليس محلياً؛ راجع الخصوصية واسمح للميكروفون. يتطلب سياقاً آمناً.
- يمكن اختيار نموذجين Ollama ومقارنة إجابتيهما في الطلب نفسه. تشغيل نموذجين معاً يستهلك ذاكرة ومعالجة أكثر، ولا يضمن نتيجة أحسن.
- البحث يفتح Bing في تبويب جديد؛ لا يسحب النتائج إلى المحادثة ولا يقدم تلخيصاً آلياً.
- ملفات النصوص في المكتبة تُضاف كمرجع للمحادثة مع النموذج المحلي (حتى حد إجمالي تقريبي 18 ألف حرف في الطلب). لذلك لا تضف ملفات حساسة إلا إذا كنت متأكداً من عنوان النموذج الذي ضبطته. PDF لا يُستخرج نصه في هذه النسخة.
- تطبيق الويب لا يتحكم بالهاتف أو يرسل رسائل أو يشتري أو ينفذ إجراءات في تطبيقات أخرى. ولا يعمل كوكيل مستمر 24 ساعة بعد إغلاق الصفحة؛ المتصفح يقيّد التشغيل بالخلفية. الإشعارات والمهام المجدولة تحتاج صلاحيات وبنية إضافية.

## الخصوصية والتكلفة والحدود

- لا يوجد خادم خلفي أو مزامنة سحابية في هذا المشروع. بيانات المتصفح لا تنتقل بين الأجهزة، ومسح بيانات الموقع يمسحها.
- عند اتصال النموذج، نص المحادثة يذهب إلى خدمة Ollama التي أعددتها (المحلية إذا كانت على نفس الجهاز). البحث يفتح موقع Bing.
- استخدام البرنامج والنموذج المحلي لا يتطلب اشتراكاً سحابياً؛ لكن الكهرباء والعتاد والإنترنت للبحث لها تكلفتها، وجودة/سرعة النموذج تعتمد على جهازك. لا يمكن ضمان أن نموذجاً محلياً مجانياً يتفوق على Claude.
- لا تُدخل كلمات مرور أو بيانات حساسة في نماذج أو أدوات لا تعرف طريقة معالجتها.
