# اختبارات واحة صغيرة

## تحديث: نسخة المتصفح اختُبرت فعلًا

- `npm test`: نجح 22 اختبارًا لمنطق JavaScript، بما في ذلك تكاليف الموارد وحدود البناء والنمو والتحقق من الحفظ والنسخة السابقة وحظر التخزين.
- `npm run test:browser` ضد خادم التطوير: نجح 29 تحققًا في Chromium مع WebGL عبر SwiftShader ومحاكاة لمس موبايل؛ الحركة والإفلات واللمس المتعدد والجمع والتصنيع والبناء والدوران والزراعة والري والحصاد والحفظ وإعادة التحميل والتوقف أثناء الحوار وحماية الحفظ التالف.
- الالتقاطات بمقاسات 390×844 و844×390 و1440×900. لا أخطاء console/page في السيناريو المتحقق.
- بعض اختبارات التدفق تستعمل مواضع اختبار ووقت محاكاة مُسرّعًا عبر seam تطويري لتغطية التفاعل بسرعة؛ ليست شهادة لاختبار اجتياز العالم كاملًا يدويًا. الإنتاج لا يصدّر `window.__oasis`.
- نجح build إنتاج، والفحوص القديمة للهيكل باقية. لا اختبار على هاتف فعلي أو قياس FPS/حرارة أو إثبات فتح دون اتصال.

تحديث الوادي: شملت الاختبارات تركيب أرضية وأربع حواف وسقف عبر أزرار لمس فعلية ثم إعادة التحميل؛ الحفظ v1 يرحّل إلى v2 مع حفظ قطع النسخة السابقة. اختبارات تضاريس مشتركة للرسم والأقدام، النهر والجسر وبطء الخوض، ودعم الحائط والسقف ومنع تكرار الحافة المشتركة. اختبارات المتصفح تضبط المخزون كـfixture لجزء البيت الكامل فقط، بعد اختبار الجمع والتصنيع الفعليين. تمت مراجعة لقطات البدء والبيت على المقاسات الثلاثة. كشف الفحص البصري حجب الشجر للشخصية وعولج بإخفاء العوائق الواقعة بين العدسة واللاعب. جُمعت الزينة الثابتة لتقليل draw calls؛ هذا لا يثبت FPS على هاتف المستخدم.

القائمة التالية تاريخ اختبار **Godot الأصلي**؛ نجاح نسخة الويب لا يثبت تشغيله أو تصدير APK.


## فصل مستويات الثقة

1. **فحوص مصدر منفذة هنا:** gdtoolkit parser/lint/formatter، مراجع ملفات المشروع، عدم وجود عميل شبكة في كود اللعبة، إعدادات أندرويد دون إنترنت، سلامة ملف الخط وترخيصه، إنشاء أرشيف مصدر وفحصه، وتباين الألوان في التوكنات.
2. **اختبارات مكتوبة ولم تُشغّل هنا:** `tests/test_game.gd` لمنطق اللعب والحفظ، و`tests/test_scene.gd` لتهيئة المشهد وأزرار التصنيع والبناء والحفظ وإعادة البدء. تتطلب Godot وتستعمل ملفات اختبار منفصلة، لا ملف تقدم اللاعب.
3. **اختبار جهاز غير منفذ:** الرسم والفيزياء والصوت/غيابه واللمس والأداء والحرارة وتجربة APK. لا screenshot للعبة أو قياسات FPS متحقق منها في هذا التسليم.

فحص الصياغة ليس فحص أنواع Godot ولا ضمانًا لواجهات المحرك. نتائج GitHub Actions لا تصبح ناجحة لمجرد كتابة workflow.

## أوامر المطور

راجع README لأوامر Python وGodot. تشغيل محرر Godot headless للاستيراد أولًا ضروري لاستيراد الخط وإنشاء كاش الموارد. اختبارات اللعبة ترجع exit code 1 عند فشل check. افحص أيضًا مخرجات Godot بحثًا عن `SCRIPT ERROR` أو أخطاء تحميل الموارد؛ بعض أخطاء تشغيل Godot قد لا تنعكس في exit code التشغيل العام.

## قيود معروفة

لا إعادة تعيين للأزرار أو تحكم بحجمها أو إعداد جودة/صوت حاليًا. القوائم مصممة أساسًا لعرض أفقي 16:9 وتحتاج تدقيق أجهزة عريضة/نوتش. معظم العناصر مجسمات منفصلة؛ تحسين draw calls لاحق بعد القياس. النموذج ليس لعبة مناسبة للنشر التجاري بعد.

## فحص إنتاج الوادي

بعد `npm run build` وتشغيل `npm run preview -- --port 5173` يمكن تنفيذ:

```bash
node web/tests/production.mjs
```

نُفذ ونجح: WebGL في إنتاج 390×844، عدم وجود hook تطوير، قراءة حفظ v1 وترحيله إلى v2 مع الجدار القديم ثم الحفظ وإعادة التحميل، خدمة التراخيص وصفر أخطاء متصفح. حزمة JavaScript قرابة 534kB قبل gzip / 141.5kB بعده؛ تحذير Vite لحجم chunk الأكبر من 500kB غير قاتل وباقٍ. تدقيق تبعيات الإنتاج: صفر ثغرات مُبلّغ عنها وقت التنفيذ.
