## تصور نسختنا المقترح، غير معتمد نهائيًا

لعبة هادئة ثلاثية الأبعاد بمنظور شخص ثالث: استكشف منطقة أصلية، اجمع موارد، اصنع أدوات، ازرع وابنِ موطنك. اللعب الفردي يثبت الحلقة الأساسية أولًا؛ التعاون الخاص المحدود يتبع ذلك. الجمهور المقترح: محبو البناء والزراعة على أندرويد؛ العمر المستهدف والأسواق يحتاجان قرارًا مستقلًا.

حلقة اللعب: استكشاف ← جمع ← تصنيع ← بناء وزراعة ← فتح وصفات ومساحات جديدة.

## التدفقات المقترحة

- F01 بداية وحفظ: S01 → S03 → S04 → S01 → متابعة S04. يشمل إغلاق التطبيق بالقوة وحفظًا تالفًا. عدد النقرات غير مقاس.
- F02 جمع وتصنيع: S04 → S05 → S06 → S04. يشمل حقيبة ممتلئة وموارد غير كافية.
- F03 بناء: S04 → S07 → S04. يشمل تصادمًا، نقص موارد، إلغاء المعاينة، وعدم خصم الموارد مرتين.
- F04 زراعة: S04 → S08 → S04. يشمل إعادة التشغيل، تغيير ساعة الجهاز، وتوقف التطبيق أثناء النمو.
- F05 رفيق مساعد: S04 → S10 → S04. لاحقًا؛ يشمل تعطل المسار وإلغاء المهمة.
- F06 تعاون: S01 → S12 → S11 → S04. لاحقًا؛ يشمل انقطاع الشبكة وتعديل نفس القطعة وإعادة الاتصال.
