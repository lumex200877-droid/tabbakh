# Original meadow assets

`meadow.jpg` and `timber.jpg` were AI-generated specifically for this prototype,
using prompts for seamless hand-painted grass and honey-oak albedo textures.
They are not extracted from Lightus/Bloxfun, Heartopia, Dawnlands or any other game.
The 3D meshes are procedural code in `web/world.js`; no commercial asset pack,
external texture service, or paid runtime dependency is needed by the game.

`replica/design/visual-target.png` is the user-selected AI concept and is **not**
a game screenshot or shipped background. Reference images under `image-search/`
are research only and are not imported by the browser build.
